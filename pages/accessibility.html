Accessibility statement · 17 July 2026

Using this demonstrator

We want people and agents to find and compare statistical metadata regardless of device, input method or assistive technology.

Current status

The demonstrator is designed toward WCAG 2.2 level AA but has not yet received a formal independent accessibility audit. It should not be described as certified compliant.

What should work

  • Navigate all controls using a keyboard.
  • Use a visible skip link to reach dataset discovery.
  • Read labelled search, facet, tab and comparison controls with a screen reader.
  • Zoom and reflow content at narrow widths without losing functions.
  • Use reduced-motion and increased-contrast operating-system preferences.
  • Read a text table for every geographic extent shown visually.
  • Open all discovery and evaluation evidence as ordinary JSON links.

Keyboard interaction

  • Tab and Shift+Tab: move through links and controls.
  • Enter or Space: activate buttons and select a result.
  • Arrow keys, Home and End: move between dataset evidence tabs.
  • Escape: use the browser’s normal behaviour; no modal traps are used.

Known limitations

  • Very large result sets are deliberately bounded in the human UI. The full machine-readable search index remains available through the OKF descriptor.
  • Geographic coverage is an extent diagram, not an interactive map. Coordinates, CRS, vintage and boundary variant are presented in a text alternative.
  • Upstream source descriptions may contain statistical terminology that is not explained in plain language by this demonstrator.
  • Automated checks cannot establish all WCAG requirements. Screen reader, keyboard, zoom and contrast checks require continuing manual review.

Technical approach

The interface uses semantic HTML, native form controls, explicit labels, visible focus, status announcements, colour-independent labels and no external mapping or user-tracking service. No API key, observation value or personal setting is stored in the browser.

Report a problem

Please open a GitHub issue with the page, browser, assistive technology and steps that caused the problem. Do not include confidential data or API credentials.
