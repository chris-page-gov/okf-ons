# LinkedIn launch post

## Main post

Ahead of Monday’s ONS hackathon, which I’m judging, I’ve published an
experiment in making official statistics easier for both people and agents to
discover.

The demonstrator packages metadata from three bounded ONS catalogue
routes—the ONS Data API, Nomis and Open Geography—into an Open Knowledge
Format bundle:

- 4,989 metadata records
- 19,570 relationships
- search and comparison designed to expose easily confused alternatives
  before a dataset is selected
- standards, provenance and evidence made visible
- geography and map-based exploration
- portable loading in OKF Explorer
- MCP selection plans covering 1,954 current bindings and 3,035 explicitly
  planned ones

This is deliberately not presented as “all ONS” yet. It is a reproducible
foundation for extending coverage while preserving source distinctions,
unresolved questions and evidence gaps.

The bundle contains metadata only—no observation data, credentials or API
keys.

I’d particularly value feedback from ONS, official-statistics, metadata,
data-discovery and MCP practitioners: can you find the exact dataset you need,
understand why it differs from its alternatives, and see a credible path from
discovery to an MCP query?
